Restoring a game takes months, so which one comes next is worth arguing about. Put something on the board, back what is already there, and the tally becomes the argument. Nothing here is a promise: a game still has to be technically feasible and legally clear before it moves to [Games](/games).

Search is wired to a game database, so titles, years and cover art come from there rather than from a form. Only PC releases from before 2010 are eligible, which is the era this project works in.
