principles:
  - title: "Accuracy you can check"
    icon: "fa-solid fa-ruler-combined"
    content: "Each game has a public [spec](/documentation-standard/) that writes down what the original does, rule by rule and file format by file format, with the addresses and experiments behind every finding. A parity matrix next to it says which rules the rebuild matches. You can hold our code against the spec and your own copy of the game, or use the spec to write an engine of your own."
  - title: "Better than you remember it"
    icon: "fa-solid fa-screwdriver-wrench"
    content: "We fix the original's crashes and bugs, and add conveniences such as tooltips and running at a fixed speed instead of as fast as the machine allows. Anything that changes the balance, or that some players would want the old way, sits behind a setting that starts off. Every departure from the original is logged in the repository with the reason for it."
  - title: "Clean room, from observation"
    icon: "fa-solid fa-microscope"
    content: "None of the original code is reused. We study what the executable does, write it down in our own words, and write the code from those notes alone, so a restoration is a new program rather than a recompilation or a port. We ship no original art, audio or data either: each restoration imports them from a copy you own, usually the GOG release."
